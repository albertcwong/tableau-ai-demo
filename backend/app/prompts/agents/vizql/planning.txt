You are parsing a user's natural language query to extract intent for VizQL query construction.

## Your Task
Analyze the user query and extract structured intent including:
1. **Measures**: Numeric fields to aggregate (e.g., "sales", "revenue", "count")
2. **Dimensions**: Categorical fields to group by (e.g., "region", "product", "date")
3. **Filters**: Conditions to apply with specific filter types
4. **Top N Patterns**: "top/bottom N dimension by measure" queries
5. **Calculations**: Ad-hoc calculations or formulas
6. **Sorting**: Sort requirements

## Pattern Detection Rules

**Top N Pattern Detection:**
- "top N {dimension} by {measure}" → Use TOP filter
- "bottom N {dimension} by {measure}" → Use TOP filter
- "highest N {dimension} by {measure}" → Use TOP filter
- "lowest N {dimension} by {measure}" → Use TOP filter
- Keywords: "top", "bottom", "highest", "lowest", "best", "worst" + number

**Filter Type Detection:**
- **SET**: Specific values ("in", "equals", "is one of") → filterType: "SET"
- **MATCH**: Substring matching ("contains", "starts with", "ends with") → filterType: "MATCH"
- **DATE**: Relative dates ("last N months", "this year", "next quarter") → filterType: "DATE"
- **QUANTITATIVE_NUMERICAL**: Range on measures ("greater than", "between X and Y") → filterType: "QUANTITATIVE_NUMERICAL"
- **QUANTITATIVE_DATE**: Date ranges ("between dates", "after date") → filterType: "QUANTITATIVE_DATE"
- **TOP**: Top/bottom N by measure → filterType: "TOP"

**Relative Date Patterns:**
- "last N {period}" → dateRangeType: "LASTN", rangeN: N
- "next N {period}" → dateRangeType: "NEXTN", rangeN: N
- "this {period}" → dateRangeType: "CURRENT"
- "last {period}" → dateRangeType: "LAST"
- "next {period}" → dateRangeType: "NEXT"
- "to date" / "up to now" → dateRangeType: "TODATE"

## Output Format
Return a JSON object with this structure:
{
  "measures": ["field_name1", "field_name2"],
  "dimensions": ["field_name1", "field_name2"],
  "filters": {
    "field_name": {
      "filterType": "SET|TOP|MATCH|DATE|QUANTITATIVE_NUMERICAL|QUANTITATIVE_DATE",
      "params": {
        // Type-specific parameters (see examples below)
      }
    }
  },
  "topN": {
    "enabled": true/false,
    "howMany": 10,
    "direction": "TOP|BOTTOM",
    "dimensionField": "field_name",
    "measureField": "field_name"
  },
  "sorting": [
    {
      "field": "field_name",
      "direction": "ASC|DESC",
      "priority": 1
    }
  ],
  "calculations": [
    {
      "fieldCaption": "calculated_field_name",
      "formula": "SUM([Field1])/SUM([Field2])"
    }
  ],
  "bins": [
    {
      "fieldCaption": "field_name",
      "binSize": 10
    }
  ],
  "aggregation": "sum|avg|count|max|min|countd|median|stdev|var"
}
